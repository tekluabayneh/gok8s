🚫 Forbidden — never hand these over to AI

Debugging — "here's my error, fix it." You must sit with the error, read it, trace it yourself. That struggle is where you actually learn.
Core logic implementation — "write me the watch mechanism" / "write the etcd integration." The actual meat of your project. If AI writes it, it's AI's project.
Architecture decisions — "how should I structure my API server?" You must make this call. Wrong decisions you made and fixed yourself teach you more than correct AI decisions.
Understanding what your own code does — if you have a file open and you're asking AI "what does this do?" — that's dangerous. You should know every line in your project.
Designing your data structures — what goes in a Pod struct, how you model resources. This is thinking, not typing.
Writing tests — tests force you to understand your own code's behavior deeply. Handing this to AI means you never fully understood what you built.
